## 日本原生IP VPS 的 IP 到底属于谁：三步验真

三类 IP 的区别，直接决定你能解锁什么。

- **原生 IP**：IPv4 归属于日本本地运营商（IIJ / OCN / NTT 等）的地址段，平台查库时看到的是“日本本地用户”。
- **机房 IP（IDC）**：归属标注为数据中心或托管服务，Netflix、Disney+ 这类平台对 IDC 段的容忍度很低。LightLayer 东京、六六云日本软银节点都属于这一类。
- **ISP 住宅 IP**：来自日本本地 ISP 的住宅段，住宅属性最强，TikTok、Instagram 这类对账号环境敏感的平台更认，价格也最高。

验证方法三步，开机十分钟能做完。

1. 终端跑 `curl ipinfo.io`，或打开 whatismyip.com，看 ASN 和运营商名。
2. 对照 ASN：IIJ 是 **AS2497**，NTT 是 **AS4713**。ASN 落在数据中心运营商名下，那它就是机房 IP，商品页写什么都不改变这个事实。
3. 再跑一遍流媒体解锁检测脚本，看 Netflix、Disney+、DMM 的实际返回。ASN 判断的是“它是什么”，解锁脚本测的是“平台现在认不认”，两件事都要看。
